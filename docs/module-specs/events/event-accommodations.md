# Event Accommodations

- Status: `Missing`
- Priority: `P3`
- Depends on: Events, Event Registrations, Accessibility Requirements, Event Travel

## Purpose
- Manage lodging, rooming, and accommodation accessibility for events.

## Minimum Records
- event_accommodations with registration_id, hotel, rooming group, accessibility needs, check-in/out

## Core Workflows
- Assign lodging.
- Track special room needs.
- Handle roommate or support-team groupings.

## Admin Surface
- Filters: event, hotel, missing room assignment.
- Metrics: rooms booked vs assigned.
- Lens: attendees with unmet accommodation needs.

## Implementation Note
- Strongly linked to accessibility requirements and care/support teams.
