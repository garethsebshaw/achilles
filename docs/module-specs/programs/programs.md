# Programs

- Status: `Missing`
- Priority: `P2`
- Depends on: Chapters, Locations, Sports taxonomy, Accessibility Requirements

## Purpose
- Represent higher-level program offerings that contain recurring workouts, events, or training tracks.

## Minimum Records
- programs with chapter, sport, seasonality, status, coordinator, description

## Core Workflows
- Define chapter program catalog.
- Group workouts and events under a program.
- Report participation by program.

## Admin Surface
- Filters: chapter, sport, active/inactive.
- Metrics: active programs by chapter.
- Lens: workouts not attached to a program.

## Implementation Note
- This can sit above workouts and events once chapter-role scope is stable.
