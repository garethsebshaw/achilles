# Awards

- Status: `Missing`
- Priority: `P3`
- Depends on: Achievements, Volunteer Recognition, Events

## Purpose
- Represent formal awards that can be conferred on users, chapters, or teams.

## Minimum Records
- awards with award type, description, criteria, season or year

## Core Workflows
- Publish award programs.
- Nominate candidates.
- Link awards to ceremonies and notifications.

## Admin Surface
- Filters: year, award type, chapter.
- Metrics: awards granted by period.
- Lens: awards with no winners selected.

## Implementation Note
- Keep the data model separate from achievements, which are system-generated milestones.
