# Assistance Requirements

- Status: `Missing`
- Priority: `P2`
- Depends on: Users, Accessibility Requirements, Care Partners, Support Teams

## Purpose
- Track the practical support a participant needs during workouts, events, or travel.

## Minimum Records
- assistance_requirements with user_id, requirement type, context, notes, approval, review date

## Core Workflows
- Capture support needs by chapter.
- Surface them in session planning.
- Link needs to staffing or care-partner assignments.

## Admin Surface
- Filters: chapter, support type, unmet need.
- Metrics: participants needing one-to-one support.
- Lens: upcoming sessions missing required support coverage.

## Implementation Note
- Separate from broad accessibility data because this is operational staffing input.
